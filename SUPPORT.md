2. **Search Existing Issues** - Your question may already be answered:
   - [GitHub Issues](https://github.com/socialawy/assetfetcher/issues)
   - [GitHub Discussions](https://github.com/socialawy/assetfetcher/discussions)

3. **Check System Requirements**:
   - Modern browser (Chrome 90+, Firefox 88+, Safari 14+)
   - Stable internet connection
   - JavaScript enabled

## 📋 When Contacting Us

### Please Include

1. **Description**: Clear explanation of the issue
2. **Steps to Reproduce**: What you were doing when the issue occurred
3. **Expected vs Actual**: What should happen vs what happened
4. **Environment Information**:
   - Browser and version
   - Operating system
   - Asset Fetcher version
5. **Screenshots**: If applicable, visual evidence
6. **Console Errors**: Any error messages from browser dev tools

[Brief description of the issue]

## ⏰ Response Times

### Business Hours
- **Monday - Friday**: 9:00 AM - 6:00 PM UTC
- **Saturday - Sunday**: Limited support
- **Response Times**:
  - Critical Issues: Within 4 hours
  - High Priority: Within 24 hours
  - Normal Priority: Within 48 hours
  - Low Priority: Within 72 hours

### Priority Levels

- **Critical**: Application broken, security vulnerability, data loss
- **High**: Major feature broken, significant performance issues
- **Normal**: Feature requests, minor bugs, usability issues
- **Low**: Documentation updates, minor improvements, general questions

### When You Contact Us

1. **Acknowledgment**: We'll confirm receipt within 24 hours
